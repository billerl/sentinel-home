3Allow location “all the time”

OwnTracks can only say when you get home if it may check your location in the background.

iPhone

  1. When OwnTracks asks for your location, tap Allow While Using App. Later iOS asks again — tap Change to Always Allow.
  2. Or do it now: Settings → OwnTracks → Location → Always, and switch on Precise Location.
  3. Allow Motion & Fitness if asked, and keep Settings → OwnTracks → Background App Refresh on.
  4. In OwnTracks, tap the mode arrow (top left) and make sure it says Significant (easy on the battery).

Android

  1. When asked for location, choose Precise, then Allow all the time. If you only see “While using the app”, pick it, then go to Settings → Apps → OwnTracks → Permissions → Location → Allow all the time.
  2. Allow notifications (OwnTracks shows a small one so Android keeps it running).
  3. Settings → Apps → OwnTracks → Battery → Unrestricted (or “Don't optimise”), so it isn't put to sleep.
  4. In OwnTracks, the mode should be Significant (easy on the battery).
